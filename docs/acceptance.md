# 真机验收清单

## 安装与权限

- [ ] Android 10+ 平板成功安装 `app-release.apk`
- [ ] 首次启动授予麦克风权限后能正常录音（麦克风音量条有响应）
- [ ] 设置页可以保存 OpenAI API Key，重启应用后仍存在

## 在线模式

- [ ] 英 → 中：外教英文讲话时，原文与中文译文流式出现
- [ ] 中 → 英：中文讲话时，原文与英文译文流式出现
- [ ] 字幕在横屏和竖屏下都不重叠、不截断
- [ ] 停止后清空字幕，再次开始正常

## 离线模式

- [ ] 在“离线模型”页下载 ASR 与 NLLB 两个模型包，进度可断点续传
- [ ] 飞行模式下选择“仅离线”能识别中英并显示译文
- [ ] Auto 模式下拔掉网络，在线失败后自动切换离线并显示提示
- [ ] 第一句结束后约 3-5 秒内出现译文

## 稳定性

- [ ] 连续 10 分钟会话不崩溃、不卡死
- [ ] 内存占用不超过平板可用内存（4GB 内存平板建议关闭后台应用）
- [ ] 下载中断后重新进入模型页可以继续下载
