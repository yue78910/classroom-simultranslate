课堂同声传译 - 预览图

文件说明：
- 课堂同声传译-预览图.html  可编辑源文件
- 课堂同声传译-预览图.png   1920x1080 预览图
- 课堂同声传译-预览视频.mp4  8秒横屏动画预览
- export-preview.bat         修改 HTML 后双击重新生成 PNG
- export-preview-video.bat   修改 HTML 后双击重新生成视频

如何自己修改：
1. 用记事本或任意编辑器打开 HTML 文件。
2. 修改标题、介绍文字、功能点、示例字幕、按钮文字和颜色。
3. 保存后双击“export-preview.bat”，PNG 会自动更新。
4. 需要动画视频时，双击“export-preview-video.bat”，MP4 会自动更新。

频谱条调整：
- 打开 HTML，在底部脚本中找到 barHeights 数组。
- 数组里的数字代表每根频谱条的高度，数值越高音量感越强。
- 增删数组元素可以调整频谱条数量。

浏览器查看：
- 打开 HTML 后右上角有“适应窗口 / 100% / ＋ / −”按钮。
- 默认自动缩放以适合窗口，点“100%”可查看原尺寸，再滚动或拖动查看。

常用颜色：
- #0F6CBD 主蓝色
- #0E8A7D 青绿色
- #B26A00 琥珀色
